Quickstart

Submit a scan:

curl -X POST {{ request.url_root }}api/v1/scan \
  -H "X-API-Key: {{ current_user.api_key }}" \
  -H "Content-Type: application/json" \
  -d '{"domain": "example.com", "sector": "financial"}'

Fetch results, then export to Splunk:

curl {{ request.url_root }}api/v1/export/splunk/JOB_ID?ndjson=1 \
  -H "X-API-Key: {{ current_user.api_key }}"
